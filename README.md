# Project B — Climate Shocks and Comparative Advantage

Research topic: extreme heat and the cotton (HS 5201) to cotton yarn (HS 5205) value chain, using country × sector × year data.

This repository will contain reusable Codex Skills under `.agents/skills/`, followed by reproducible data processing, RCA computation, and econometric scripts. The Skill instructions do not replace Python libraries or data sources.

Source of the third-party economics Skills: https://github.com/JonasWeinert/EconAgentSkills (CC0 1.0). These files are examples and instructions; review code before execution.
